# Converge on one known-answer fixture before adding more agents

The existing work has several complementary witnesses. The useful next step
is to send **one small asymmetric scientific fixture** through them while
retaining independent questions at every boundary.

## Fixture

Reuse the Research Loom mixed fixture as the geometric seed: an asymmetric
tetrahedron, a sampled line and a point set, with distinct colors, opacity,
group identifiers, scientific scalar values, units and a nonzero origin. Add
explicit ColorRGBA and unlit variants as separate candidates. Keep the original
Float64 scientific packet, its stable IDs and known-answer values beside every
projection. Do not turn the new variants into claimed executed results merely
by adding them to a catalog.

One invariant sheet should state:

1. exact record and point counts, coordinates and connectivity;
2. the right-handed frame, proper Y-up/Z-up rotation and reversible origin;
3. scientific values, units, color mapping and missing-value conventions;
4. the supported projection for each hub and its expected losses;
5. which parts of the picture are authored appearance.

## Use existing tools for the question each can answer

| Gate | Existing instrument | Keep the answer narrow |
|---|---|---|
| Construct and publish | Research Loom case contract and atomic bank writer | Packet invariants, explicit witness inequalities and immutable bytes |
| Structural validity | Pinned x3d_mcp schema and semantic adapter | Named schema/version and implemented semantic checks |
| Actual scene values | Owned X3D/VTK readers | Coordinates, topology, arrays, units and grouping that the projection promises |
| Blender transfer | Owned bridge plus independently probed stock/fork paths | Measured save/reopen values, explicit losses and actual-vertex mutation controls |
| Third geometry path | Existing Blender glTF exporter and reimport receipt | Expanded mesh geometry and serialized/reimported colors, with quantization stated |
| Figure continuity | Existing x3dprov implementation and figure-link adapter | Hash-chain/content continuity and exact external image/receipt identities |
| Interpretation | Human experiment and scoped ontology assertions | Whether a viewer can explain the variable, assumption and counterexample |

The inventory joins those original records. It does not become another
validator or figure-signing system.

## Baseline, intervention, comparison

Freeze the pre-fix source commits, fixture bytes and per-route loss ledger.
Choose one repair, such as ordinary PointSet export in the ecosystem fork.
Rerun the same invariant sheet and both the matching positive fixture and a
deliberate incorrect twin. Compare the affected counts and attributes; leave
unaffected dimensions unclaimed. Only then add the corresponding bridge
completion evidence to its owning catalog.

For appearance parity, use a separate unlit color chart and recorded camera,
lighting, alpha compositing, background and display settings. Pixel difference
is meaningful only after those choices are aligned. Record failed pairs as
useful evidence rather than choosing whichever renderer mode produces the best
score for each row.

For the splat branch, the new four-splat SH3 probe establishes a bounded native
attribute-layout observation. The old N/SH/opacity/scale ladder remains its own
experiment. Extend the common invariant sheet with explicit log/linear scale,
logit/alpha, quaternion order, SH basis/channel ordering, axis transform and
numeric tolerances. Do not extrapolate a small raw-data test to pixels, a
65k/1M-splat limit, or arbitrary transformed covariance.

## Acceptance record

A useful completed comparison has original inputs, exact tool builds, raw
results, expected and observed losses, the scope of each facet, and one
mutation that its oracle rejects. The bridge map then points at that evidence.
There is no need to collapse all facets into a single pass percentage.
