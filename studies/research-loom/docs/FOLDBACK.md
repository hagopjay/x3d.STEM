# Findings carried back into the scientific Loom

The three instruments add a compact, researcher-oriented path alongside the
repository's larger domain studies. Existing stemkit rejection and atomic-write
helpers are reused. Publication eligibility is enforced separately: all nine
case candidates must pass before a new hash-bound bank index becomes visible.
Export directories include the case digest, so an interrupted new build cannot
silently replace exports referenced by an older green index.

## A scientific claim needs several different witnesses

| Layer | Witness | What it cannot establish |
|---|---|---|
| Model | ABC divergence/curl identities, covariance reconstruction, membrane spectra and energy | Pixel clarity, a real dataset's assumptions, or arbitrary parameter validity |
| Numerics | DOP853 comparison, discrete eigenproblem and refinement, independent covariance/quadratic form | A universal theorem or all future times |
| Publication | Reopened bytes, immutable paths, packet and frame hashes | Publisher authentication or scientific correctness by itself |
| Representation | Actual decoded coordinates/topology/colors, raw point arrays, periodic seams | Identical appearance in every renderer |
| Hub transfer | VTK readers, Blender save/reopen/export, actual-coordinate tamper controls | Recomputed solver evidence after geometry edits |
| Renderer | Case/frame-bound Blender CPU render receipt | Native X_ITE frame rate, browser-identical pixels, or GPU performance |

The distinction matters in the ecosystem: stemkit's `Study.save_case` can write
a red case before a caller exits with failure. A valid serialized record and an
eligible public scientific case are separate decisions. This new study checks
every declared witness and its inequality before publication and in browser
acceptance. It does not claim certification by an external profile absent from
the checkout.

## Import identity must follow the bytes

Independent review reproduced a subtle CSV issue: numerically identical rows
with reordered headers could reuse a point-cloud ID while carrying different
input provenance. Keeping the first matching UI record could then label a new
frame with old bytes. Imports now include input identity, upsert UI records,
return the exact canonical packet string, and bind frame requests to its SHA.
Requests with a different stored digest are rejected. Cached producer code is
also bound to a server-start snapshot; source edits require restart.

## Blender lessons from actual execution

The owned bridge uses the proper rotation `(x,y,z)→(x,−z,y)`. An asymmetric
control checks handedness and scale. Centerlines and point positions are
measured from actual Blender glyph vertices on return, rather than accepted
from cached metadata. Vertex colors use explicit sRGB/linear conversion;
Blender's convenience conversion introduced a larger measured error in the
first control. A deliberate actual-coordinate edit must fail the comparison.

A performance trap appeared in real multi-megabyte packets: writing one very
long JSON line into a Blender Text block made source retention stall. The
adapter now stores losslessly compressed, bounded, line-chunked source text
with a decoded SHA check. This changes representation, not scientific numbers.

The stock X3D extension accepted the control but exported an older version and
dropped lines, points, colors and metadata. The modern ecosystem fork retained
substantially more of the fixture, but omitted its ordinary point set. Their
receipts distinguish execution from retention. These bounded observations
support targeted fixes; they do not establish general extension conformance.

## Display semantics belong beside the picture

Flow lines wrap through a periodic cube; connecting a seam directly across the
box would invent a trajectory. Intersections are linear clipping constructions,
not newly integrated states. Tensor playback changes probability thresholds,
not observations or physical time. Three-dimensional radius one covers about
19.9% under a known Gaussian, not the familiar one-dimensional 68%. The mixture
case makes a global covariance summary's limitation visible.

Membrane height is magnified independently of in-plane coordinates. VTP carries
unmagnified displacement/velocity arrays; numerical gradients computed directly
on the display mesh therefore need the declared coordinate mapping. Sparse
saved frames are identified as checkpoints, particularly when a long beat
envelope is retained as data rather than portrayed as a resolved movie.

## Integration route

Keep computational models and witnessed case banks in x3d.STEM. Propose a
versioned, owner-numbered discovery card to x3d.demo rather than duplicating or
overwriting its gallery. Move reusable coordinate, evidence and hub contracts
into x3d.docs, where each can become a short drill with a deliberate failure.
The root assessment gives the exact inspected repository revisions and a
bounded three-stage roadmap. No upstream repository or deployment is changed
by this local delivery.
